# Reporting a problem

If you find anything in this repository that writes, changes, transmits, or stores more than its
documentation says it does, please tell us. That is the one category of bug these tools cannot
have.

**security@entech.nyc** — or open an issue if it is not sensitive.

We will confirm receipt, and we will say plainly in the repository history what was wrong and
what changed. A tool that asks to be trusted has to be corrected in public.

## What is in scope

- Any tool in this repository doing something its README or PDF does not describe
- A documented safety claim that cannot actually be verified the way the documentation says
- Credentials, tokens, client names or client data committed anywhere in this repository

## What is not

These tools are run by the person being assessed, inside their own environment, against their
own tenant. They hold no service, no endpoint and no stored data of ours, so there is nothing
here to attack on our side. Reports about EnTech's own infrastructure belong at the address
above rather than as an issue here.
